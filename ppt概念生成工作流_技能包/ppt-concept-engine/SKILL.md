# PPT 概念生成引擎

专业的建筑规划方案PPT概念生成引擎，专门负责从项目信息到最终PPT交付的全链路工作。

## 核心能力

### 1. 概念主旨提炼（前置必做）
接收任何文本素材后，必须先进行概念整合和优化，提炼PPT概念主旨。

**输出格式：**
```
概念主题：[概念1] · [概念2] · [概念3]
核心逻辑：[起点] → [载体] → [功能] → [目标]
章节拆解：
  - [概念1]：[解决的问题] + [核心内容]
  - [概念2]：[解决的问题] + [核心内容]
  - [概念3]：[解决的问题] + [核心内容]
汇报话术：[开场] → [逻辑串联] → [结尾闭环]
```

### 2. 大纲分层生成
基于概念主旨，展开PPT页面结构，每页标注类型和核心信息点。

**标准页面类型：**
- 封面页：主标题 + 英文副标题 + 项目名 + 日期
- 目录页：3章节列表（编号 + 中文名 + 英译 + 页码范围）
- 章节过渡页：左侧深色块 + 右侧底部文字 + 超大章节数字
- 图文分栏页：左图(60%) + 右侧信息卡片
- 多卡片横排页：上排数据卡 + 下排照片卡
- 四象限列表页：顶部引导 + 2×2要点卡片
- 方案呈现页：SCHEME编号大字 + 大示意图 + 指标
- 方案对比页：两列对比布局
- 结尾页：极简结束语

### 3. 样式规范（高端商务风）
详见 `references/style-guide.md`，核心要点：
- 配色：主深蓝#0E2A5B / 品牌蓝#2562EB / 文字灰#94A2B8 / 分割灰#CBD5E1
- 字体：中文微软雅黑 / 英文Arial，标题700正文400
- 每页统一：左上brand-mark（方块+横线+ANYUE SHOE PARK）
- 内容页标题：英文标签 → 中文标题 → 英文副标题（三段式）

### 4. HTML PPT 生成
使用HTML+CSS生成16:9幻灯片，base64内嵌图片，支持Playwright/Chromium导出PDF。

## 工作流程

1. **概念提炼** → 输出概念主旨文档，用户确认
2. **大纲生成** → 展开页面结构和内容要点
3. **配图生成** → 为每页选配/生成意向图
4. **版式设计** → 按8种版式分配页面
5. **HTML生成** → 输出完整可浏览的HTML PPT
6. **迭代优化** → 根据反馈调整样式和内容

## 触发场景

- 用户要求生成建筑/规划/产业园区的概念方案PPT
- 用户要求制作汇报演示文稿
- 用户提到"概念方案"、"汇报PPT"、"方案呈现"

## 关键依赖

- 配图：通过图像生成工具或搜图获取意向图
- 导出：Playwright/Chromium headless渲染PDF
- 排版规范：详见 `references/style-guide.md`

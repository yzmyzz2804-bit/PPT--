# v6.1 A3迁移、接入与反馈

本次确认：打印版使用A3。默认横向；正文14pt、标题28pt、标签及来源12pt均为项目建议。

## 执行顺序
1. 解压到新的独立项目目录，保留旧v6包和运行文件。不要覆写Architect OS。
2. 将TRAE_START_HERE.md发送给TRAE；加载短规则与项目技能。
3. 跑自检，填config/tool_bindings.template.json的副本和templates/acceptance_report.json的副本到当前run中。
4. 提供真实PPT、相关纪要和底层数据；自动识别与归档，约束汇总确认。
5. 在批准范围内生成汇报版与原生A3版；运行实际PDF图幅校验，留存证据。
6. 逐页视觉、数字、跨版和打印验收；审批后发布；反馈生成下一版升级提案。

## 迁移边界
print_a4改为print_a3属于不兼容的输出规格变更；旧运行保留旧配置锁，不直接改旧state或旧审批。
新建运行，复制原件并记录同一来源SHA；重新建立约束/内容/发布审批，旧审批不可自动继承。
行业事实网站仍待真实业务主题确定后补充；不能把设计网站当行业数据源。

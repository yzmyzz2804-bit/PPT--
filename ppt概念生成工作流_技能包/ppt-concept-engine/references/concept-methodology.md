# PPT 概念主旨提炼方法论

## 核心原则

PPT概念不是对项目信息的简单罗列，而是建立一套自洽的叙事逻辑，让甲方/评委在有限时间内快速理解方案价值。

## 提炼流程

### 第1步：核心特征提取
从项目输入中识别关键要素：
- **用地特征**：区位、面积、周边条件、场地现状
- **产品形态**：建筑类型、层高、标准层面积、柱网
- **目标客群**：产业类型、企业规模、用户画像
- **数据指标**：容积率、面积、密度、绿化率、停车数

### 第2步：概念抽象
将具体特征提炼为 3-4 个概念词（每词 2-4 字）：
- 要抽象，不要写实（不说"厂房"说"智造"）
- 要有逻辑关联，不是独立关键词堆砌
- 要能形成递进或因果关系

**常用概念词库：**
- 产业类：共生、聚合、赋能、生长、智造、创新、孵化、集群
- 空间类：弹性、集约、立体、复合、渗透、链接、脉络
- 生态类：共生、循环、低碳、韧性、自然、有机
- 运营类：平台、引擎、枢纽、社区、生态圈

### 第3步：逻辑链构建
建立概念间的关系：
- **递进式**：基础 → 升级 → 目标（如：场地研判 → 产业洞察 → 方案呈现）
- **因果式**：因为A所以B，B实现C（如：产业共生 → 智造赋能 → 弹性生长）
- **总分式**：一个核心概念 → 三个支撑维度

### 第4步：叙事闭环
确保概念能回答四个核心问题：
1. **在哪建？** → 场地/区位（场地研判）
2. **建什么？** → 产品/形态（技术策略）
3. **怎么建？** → 方案/布局（方案呈现）
4. **为什么好？** → 价值/效益（对比总结）

### 第5步：汇报话术转化
将逻辑链转化为可讲述的汇报语言：
- **开场**：一句话抛出概念主题
- **展开**：每个概念配一个设问，自问自答
- **收束**：回到概念主题，形成闭环

## 输出格式

```
概念主题：[概念1] · [概念2] · [概念3]
核心逻辑：[起点] → [载体] → [功能] → [目标]

章节拆解：
  - [概念1]：[解决的问题] + [核心内容]
  - [概念2]：[解决的问题] + [核心内容]
  - [概念3]：[解决的问题] + [核心内容]

汇报话术：
  开场：[一句话概念引入]
  展开：[逻辑串联，每章一个过渡]
  收尾：[回到主题，闭环升华]
```

## 章节顺序经验

**最优叙事顺序：**
1. 战略势能（为什么在这建）
2. 场地研判（场地条件如何）
3. 案例借鉴（行业怎么做的）
4. IP引擎（项目核心价值）
5. 技术策略（产品怎么设计）
6. 形态过渡（到方案的衔接）
7. 方案呈现（总方案/多方案）
8. 经济技术对比（数据支撑）

> 注意：「形态概念」不做独立章节，作为技术策略到方案的过渡页。

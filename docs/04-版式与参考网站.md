# 双版式与优先参考站点 · A3修订

## 用户已确定与项目默认
用户明确打印版采用A3图幅。方向未指定，本包默认横向420×297毫米；如需竖向，在任务契约中明确为297×420毫米再批准，不能靠驱动自动旋转。

| 项目 | 现场汇报版 | A3打印阅读版 |
|---|---|---|
| 画布 | 16:9，13.333×7.5英寸 | 原生A3横向420×297毫米 |
| 标题/正文 | 32/24pt | 28/14pt |
| 图表标签/来源说明 | 20/18pt | 12/12pt |
| 边距 | 画布5%安全区 | 四边15毫米，内容区390×267毫米 |
| 布局 | 一页一个核心信息任务 | 同一信息任务可有相关证据分区，建议不超过3个主区 |
| 打印方式 | 不作为A3阅读版的替代 | 100%实际大小、一页一张；不自动适配或N合1 |

字号、边距与密度为可调整的项目建议，不是用户已批准的母版或行业强制标准。A3不等于把A4所有元素按比例放大，也不等于可以塞满小字。正文14pt作为默认，标签/来源12pt，不足优先简化或分页。
正文和标题优先真文本、图表优先可编辑或矢量；不要将整页截图当作可编辑PPT。栅格图在最终纸面尺寸下检查有效清晰度，低于150dpi触发项目预警，不靠插值宣称高清。
输出PDF检查每页MediaBox和CropBox均符合已批准方向的420×297mm（容差1mm）；混入A4或16:9原尺寸即不通过。
额外图框、出血、裁切线、双面装订边均未被用户要求，本包不自动启用。需要工程图框/企业模板时另行提供并审批。

## 两版内容关联
汇报与打印共用claim_id与核验账本；页数可不同，打印可以增加解释、方法与来源，但不能改变数值、单位、时间口径与结论。
保护版式不得直接重排；新增A3派生版本也应在契约中明确授权。未授权时仅输出方案。
`print_same_slides`仍只是原16:9幻灯片直接打印辅助配置，不满足原生A3阅读版要求。
Markdown控制层级与信息结构，实际字体和图幅由渲染器与PDF校验负责。

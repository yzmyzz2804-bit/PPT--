# 几何规则与排错（cad-massing-to-sketchup）

## 1. 堆叠 z 值模型（每栋 n 层、层高 fh、板厚 t）

以 ±0.000 为室外地坪，玻璃体从 0 起始：

```
第 i 层 (i = 0 … n-1):
  玻璃体:  z = i*fh            →  i*fh + (fh - t)
  楼板:    z = i*fh + (fh - t) →  (i+1)*fh      # 每层顶部的板；顶层板即屋面板
女儿墙:     z = n*fh 起，高 hp（1.5m；n=1 时 1.0m），厚 0.2m 沿轮廓内偏
建筑总高 = n*fh + hp
```

- 板厚判定用**层高**而非总高：fh ≤ 5m → 0.6m；fh > 5m → 0.7m。
- 不设基座楼板、不建内核、不开洞——纯堆叠体量，接口面只接触不重叠，无 z-fighting。
- 楼板与玻璃体同轮廓（边对边），女儿墙为独立薄墙（相邻墙平行内偏，凹角处允许微小楔形缝，塑模尺度不可见）。

## 2. SketchUp 端结构（.rb 脚本生成）

```
模型
├─ Group "B01-11F"            # 每栋一组，名字 = 栋号-标注
│  ├─ Group "玻璃体"   → Tag 玻璃体   材质 体块-玻璃 (RGB 176,208,228, α0.35)
│  ├─ Group "楼板"     → Tag 楼板     材质 体块-楼板 (RGB 238)
│  └─ Group "女儿墙"   → Tag 女儿墙   材质 体块-女儿墙 (RGB 248)
└─ Group "B02-18层" ...
```

- 全部为原生 Face + pushpull，绝无三角网格/C点/余线；一次 `start_operation` 完成，可一步撤销。
- 坐标：脚本内一律乘 `IN = 1/0.0254` 转 SU 内部英寸单位。
- 建组前用 `f.reverse!` 归一面法线再 `pushpull`，保证方向恒向上。
- 女儿墙按边生成四棱柱；先算多边形绕向（shoelace），CCW 取左法线、CW 取右法线作为内偏方向；短于 2cm 的边跳过。
- 运行结束 `zoom_extents` + 弹窗"N 栋完成"；失败自动 `abort_operation` 回滚。

## 3. parse_dxf.py 细节

- 轮廓候选：闭合 LWPOLYLINE / 2D POLYLINE；面积 < `--min-area`(默认 20m²) 丢弃；同图层质心重合、面积差 <1% 判为重复轮廓只留一个。
- bulge 弧段按约 7.5°/段展开为折线（单段上限 64），保证弧线楼栋轮廓平滑且点数可控。
- 层数正则 `(\d+)\s*(?:F|f|层)`，MTEXT 先 `plain_text()` 去格式；文字必须落在轮廓 bbox 外扩 5m（`--margin`）内，多候选时取距质心最近者，一文字只归一栋。
- 单位判定顺序：`--unit` > `$INSUNITS`(4=mm, 5=cm, 6=m, 1=in, 2=ft) > 尺度推断（轮廓总幅 >1000 视为 mm）。**推断结果必须向用户复述确认**。输出 JSON 一律米。
- `needs_review` = 轮廓旁无层数文字；`unmatched_texts` = 有层数样式但没归上轮廓的文字。两者都必须人工/对话解决后才可进 gen 步骤（gen 会硬性拦截 floors=null）。

## 4. 排错

| 现象 | 处置 |
|------|------|
| 楼栋数明显偏多 | 总图里的道路/铺装闭合框被抓进来 → 让用户给建筑轮廓图层名，加 `--layers`；或调大 `--min-area` |
| 层数抓错/串栋 | 文字离轮廓太远 → 加大 `--margin`，或让用户直接报"栋号=层数"清单手填 JSON |
| 单位不对（模型巨大/极小） | 用 `--unit mm` 或 `--unit m` 显式指定；或 `--scale` 补系数 |
| 层高与板厚冲突（fh ≤ t） | gen 报错退出 → 层高输错，回对话确认 |
| 弧线楼栋出现折棱 | 属正常分段；如需更平滑，减小 parse_dxf.py 的 `deg_step`（如 4.5°） |
| SU 运行报 UTF-8 乱码 | 确保 `.rb` 首行 `# encoding: UTF-8` 且文件本身为 UTF-8 编码 |
| SU 2020 及以下 tags 无效 | 脚本已自动回退 `layer=`，无需处理 |
| 用户只有 DWG | 让其在 CAD 中 `SAVEAS` 导出 DXF（任一 2000+ 版本），技能不解析 DWG |

## 5. 修改脚本的自检

任何脚本改动后：在临时目录用 ezdxf 造一个含"矩形多层楼（11F）+ 带弧线单层楼（1F）+ 无标注楼 + 干扰小框 + 未闭合线"的样例 DXF，完整跑通 parse →（手填层数）→ gen；随后运行 `python scripts/check_rb.py <生成的.rb>` 校验编码声明、注释完整性、Ruby 块配对与关键调用。必须覆盖的断言点：单位推断为 mm、needs_review 命中无标注楼、单层女儿墙 1.0m、层高 6.0m 时板厚 0.7m、.rb 末行 `Tikuang.run`。

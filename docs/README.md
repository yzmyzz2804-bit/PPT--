## 表格与配置的关系
执行事实源为config/layout_profiles.json，表格是人可读对照，不自动覆写配置。
config/layout_table_mapping.json逐行绑定32个规范字段、8列文字及相关JSON字段值。
运行python scripts/validate_layout_table.py可查文字漂移、配置漂移、缺行、重复字段、建议值被静默启用。
原表标题中的v6.1代表表格的历史配置基线，当前活动工程版本为7.2.0；原表不改写，两者不冲突。

# 高端商务风 PPT 样式规范

> 版本：v1.0
> 基准：安岳鞋服加工园区项目（用户手动调整版）
> 适用：产业园区 / 建筑规划 / 方案汇报类PPT

## 一、整体风格

高端商务极简风，蓝灰主色，大留白，卡片式信息组织。

## 二、配色体系

### 主色（蓝色系）
| 色值 | 用途 |
|------|------|
| `#0E2A5B` | 品牌主色 / 标题文字 / 章节页深底 |
| `#1D3A8A` | 次级强调色 / 重要数字 |
| `#2562EB` | 品牌亮蓝 / 图标/装饰线/链接 |
| `#3B81F5` | 辅助蓝 / 高亮态 |
| `#60A5FA` | 浅蓝 / 辅助装饰 |
| `#93C4FD` | 更浅蓝 / 底纹/淡背景 |
| `#BEDAFE` | 极浅蓝 / 卡片淡背景 |

### 中性灰
| 色值 | 用途 |
|------|------|
| `#000000` | 纯黑（极少用） |
| `#94A2B8` | 次级文字 / 英文标签 / 页码 |
| `#CBD5E1` | 分割线 / 装饰线 / 弱边框 |
| `#E2E7F0` | 卡片边框 / 表格线 |
| `#F1F5F9` | 浅灰底 / 卡片底色 |
| `#F7FAFB` | 更浅灰底 / 页面底色 |
| `#FFFFFF` | 白色 / 卡片背景 |

### 功能色（极少使用）
| 色值 | 用途 |
|------|------|
| `#049569` | 成功/绿色（数据指标） |
| `#DB2525` | 警示/红色（风险标注） |

## 三、字体体系

### 字体栈
- **中文**：Microsoft YaHei → PingFang SC → Noto Sans SC → sans-serif
- **英文/数字**：Arial → Helvetica → Inter → sans-serif

### 字号层级（1920×1080px 画布）
| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| 超大标题 | 72-96px | Bold | 封面主标题 / 章节超大数字 |
| 大标题 | 44-56px | Bold | 章节页中文标题 |
| 页面标题 | 32-36px | Bold | 内容页主标题 |
| 卡片标题 | 20-24px | SemiBold | 卡片/信息块标题 |
| 正文 | 16-18px | Regular | 正文文字 |
| 说明/标签 | 13-14px | Regular | 注释、标签、辅助文字 |
| 英文小字 | 12-14px | 500/600 | 英文小标题/页码/品牌标识 |

### 字重规则
- 中文标题：700
- 中文正文：400
- 英文标题/标签：500-600，letter-spacing: 2px
- 数字：600，走英文字体

## 四、页面结构

### 每页统一元素

**左上角品牌标识（brand-mark）：**
- 小方块（14×14px）+ 短横线（36×2px）+ 英文小字
- 颜色：#CBD5E1（方块和线）/ #94A2B8（文字）
- 文字：项目名英文大写，字母间距大
- 位置：左上，距边约 40-50px

**内容页标题区：**
- 最上方：英文标签小字（12-14px，字母间距2px，#94A2B8）
- 中间：中文大标题（32-36px，Bold，#0E2A5B）
- 下方：英文副标题（16px，Arial，#94A2B8）
- 整体靠左对齐，上边距约 60-80px

### 8种标准版式

#### 1. 封面页
- 右半侧布局，主标题偏右下
- 主标题：72px+ 超大字，左右有装饰横线
- 主标题下英文小字副标题
- 底部：项目名称 + 日期
- 背景：深蓝色调 + 意象图淡化叠加

#### 2. 目录页
- 极简风格，无多余装饰
- 顶部：CONTENTS 英文小字（左上）
- 3个章节条目，每条高约 100-120px
- 每条结构：大编号（01/02/03）+ 中文章节名 + 英文译名 + 右侧页码范围
- 左侧有细竖线装饰（#CBD5E1）
- 背景：纯白/极浅灰

#### 3. 章节过渡页
- 左侧约 45% 深色块（#0E2A5B 深蓝底），占满高度
- 右侧白色区域，底部放文字
- 超大数字（半透明蓝，巨大号）
- 章节中文标题（在数字下方/旁边）
- 章节英文全称（底部）

#### 4. 图文分栏页（左图右文）
- 左侧大图区（约 60% 宽度）
- 右侧信息区（约 40%）
- 右侧 2-3 张信息卡片，竖向排列
- 卡片：浅灰底 + 极细边框 + 顶部/左侧装饰线

#### 5. 多卡片横排页
- 上排：3张并列数据卡片
  - 每张：大数字 + 类别名 + 键值对列表
  - 数字居中放大，下方信息左右分栏
- 下排：3张企业/项目照片卡片
  - 照片占主要面积
  - 底部半透明条带写名称+标签

#### 6. 四象限列表页
- 顶部有一段引导文字（占满宽，左侧有竖线装饰）
- 下方 2×2 排列四个要点卡片
- 每个卡片：标题 + 3个圆点列表
- 底部可有一行总结文字

#### 7. 方案呈现页
- 顶部：SCHEME 01 / SCHEME 02 英文编号大字
- 主体：方案总平图/示意图占大区域
- 侧边/下方：方案说明与核心指标

#### 8. 方案对比页
- 两列对比布局
- 每列有方案标题、核心指标列表
- 关键差异点用颜色或图标强调

## 五、组件规范

### 卡片（Card）
- 背景：白色 #FFFFFF 或 极浅灰 #F7FAFB
- 边框：1px solid #E2E7F0
- 圆角：4-8px
- 内边距：24-32px
- 顶部/左侧可有 3-4px 装饰条（#2562EB 亮蓝）
- 阴影：极淡或无，走扁平风

### 分隔线
- 颜色：#CBD5E1
- 粗细：1-2px
- 装饰短线：36px

### 数据展示
- 大数字颜色：深蓝 #0E2A5B 或 亮蓝 #2562EB
- 单位/标签：小一号字，灰色 #94A2B8
- 数字使用英文字体

## 六、设计原则

1. **克制用色**：主色只用蓝色系，每页强调色≤2处
2. **大留白**：边距充足（80-100px），元素不拥挤
3. **中英双标题**：所有中文标题配英文小字副标题
4. **数据放大**：关键数据用大字号突出，不跟正文混
5. **装饰极简**：只用方块+横线的品牌标识
6. **左对齐为主**：标题、正文一律左对齐，数字卡片可居中
7. **图文分栏明确**：有图时图占主视觉区（>50%宽度）
8. **信息层级清晰**：每页不超过3级标题层级
